# Xinyu Liu Homepage

Static academic homepage for `https://liuxinyv.github.io/`.

## Files

- `index.html`: biography, two-part research agenda, publications, and experience.
- `style.css`: responsive desktop and mobile styling.
- `assets/lxy.jpg`: profile photo.

## Preview

```bash
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000/` in a browser.

## Maintenance

Update the representative-work cards when a paper changes status. Keep the research statement stable unless the long-term research agenda changes; use the Recent Updates section for short-term news.
